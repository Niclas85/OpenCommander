  a selected directory symlink. Broken links retain their own metadata and target.

  read-only volume, capacity/free space, and link-target fields are displayed.
- Missing reads remain explicitly unknown, never fabricated zero/false. Symlink
  access stays unknown because `access()` would describe its target instead.

  NAS/cloud; access at observation time cannot guarantee a later mutation.
- The local dialog now uses the existing selectable, scrollable information sheet.
  Directory content size is unknown until the bounded scan is explicitly requested;
  selected links never offer that scan.
- Online properties no longer label an account/profile name as file permissions;
  unavailable permissions remain unknown with the same provider qualification.
- Follow-up formatting uses neutral `B` for small byte counts instead of the
  system-language-dependent English “bytes” in the German properties display.
- A slow network-directory message now mentions server/share reachability instead
  of exclusively suggesting cloud authentication. No networking/security settings
