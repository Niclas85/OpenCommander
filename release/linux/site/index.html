OpenCommander

Ein quelloffener Dateimanager mit zwei Dateibereichen für Kopieren, Verschieben, Vorschau und nachvollziehbare Übertragungen.

Desktop-Versionen für Linux und Windows

OpenCommander verwendet unter Linux und Windows denselben Qt-Anwendungskern. Dateioperationen, Vorschauen, Archive und Cloud-Verbindungen wurden praktisch geprüft. Google verwendet eine eigene Desktop-OAuth-Anwendung; ihre öffentliche Verifizierung steht noch aus. Der aktuelle Testmodus ist keine allgemeine Freigabe.

Jeder Nutzer verbindet sein eigenes Cloud-Konto. OpenCommander betreibt keinen zentralen Server für deine Dateien.
